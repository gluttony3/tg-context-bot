# Telegram AI Summary Bot

Telegram-юзербот, который кэширует сообщения из супергруппы с топиками в SQLite и позволяет получать саммари, отвечать на вопросы по содержимому группы и искать упоминания через Gemini AI.

## Команды

Все команды отправляются **из «Сохранённых сообщений»**:

| Команда | Описание |
|---------|----------|
| `/id` | Узнать ID пересланной группы |
| `/summary` | Саммари за 48 часов (вся группа) |
| `/summary 123` | Саммари за 48 часов по конкретному топику |
| `/mentions Иван` | Поиск упоминаний пользователя в БД |
| `/ask вопрос` | Вопрос-ответ по содержимому группы (RAG) |

## Получение ключей API

### 1. Telegram API_ID и API_HASH

1. Перейдите на [my.telegram.org](https://my.telegram.org)
2. Войдите под своим номером телефона
3. нажмите **API development tools**
4. Заполните форму (App title, Short name — что угодно)
5. Скопируйте **App api_id** и **App api_hash**

### 2. Google Gemini API_KEY

1. Перейдите на [aistudio.google.com](https://aistudio.google.com/apikey)
2. Войдите под Google-аккаунтом
3. Нажмите **Create API Key**
4. Скопируйте созданный ключ

### 3. TARGET_CHAT_ID

1. Запустите бота (инструкция ниже)
2. Перешлите любое сообщение из нужной группы в **Сохранённые сообщения**
3. Отправьте `/id`
4. Бот ответит с ID группы (отрицательное число, например `-1001234567890`)
5. Впишите этот ID в файл `.env` в поле `TARGET_CHAT_ID`
6. Перезапустите бота

## Запуск

### Шаг 1 — Клонируйте проект

```bash
git clone <url-репозитория>
cd telegram-ai-summary
```

### Шаг 2 — Настройте переменные окружения

```bash
cp .env.example .env
```

Откройте `.env` и впишите ваши ключи:

```
API_ID=12345678
API_HASH=abcdef1234567890abcdef
GEMINI_API_KEY=AIzaSy...
TARGET_CHAT_ID=-1001234567890
```

### Шаг 3 — Запустите

**Windows:**

```
start.bat
```

**Linux / macOS:**

```bash
chmod +x start.sh
./start.sh
```

**Termux (Android):**

```bash
chmod +x start.sh
./start.sh
```

При первом запуске Telethon попросит ввести номер телефона и код — это нормально.

## Как это работает

1. **Кэширование**: при запуске бот догружает новые сообщения из группы (если БД пуста — последние 100)
2. **Эмбеддинги**: фоновый поток индексирует сообщения через `gemini-embedding-001` и сохраняет в SQLite
3. **Команды**: `/ask` делает RAG-поиск по эмбеддингам и отправляет контекст в Gemini; `/summary` суммирует сырые тексты
4. **Очистка**: сообщения старше 7 дней удаляются автоматически раз в сутки
